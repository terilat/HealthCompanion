# HealthCompanion Telegram Bot (skeleton)

Базовая заготовка телеграм-бота на `python-telegram-bot` 22+.

## Быстрый старт

1) Установить зависимости:

```bash
pip install -r requirements.txt
```

2) Задать токен:

```bash
export TELEGRAM_BOT_TOKEN="123:ABC"
```

3) Запуск:

```bash
python LLM/HealthCompanion/run_bot.py
```
